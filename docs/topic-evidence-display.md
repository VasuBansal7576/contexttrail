# Topic evidence display

Research-question reports (`source_assertions`) display retained source assessments
in descending model-assessed topic relevance by default. Equal values retain their
original order. Unassessed sources appear after assessed sources, carry an explicit
unassessed label, and are never assigned a zero value. The original retrieval order
is available through a visible control; changing order resets pagination to the
first page. No sources are filtered or collapsed.

Every assessment card exposes its retained relevance outside the inspection
details, including the existing low-relevance lead warning for values below 0.5.
Relevance concerns the research question; it does not establish factual accuracy,
authority, independence, or support for a claim. Explicit-claim reports retain
their existing source order and have no topic ordering control.

The display sorts a copy of the original report assessments. Saved and historical
reports use those retained assessments and their original source snapshot, rather
than changed workspace evidence. Quotes, relationships, probabilities, candidate
audit, source identifiers, evidence bindings and archive arrays are unchanged.

This improves access to already-retained material. It does not change acquisition,
search queries, page-read budgets, model calls, primary-source coverage, or recall.
The Chenab-shaped regression represents one relevant second source and seven
low-relevance leads. It does not claim a new search outcome or a synthesized answer.

Component controls cover unknown versus zero, stable ties, all-low/all-unassessed
samples, relevant challenges, explicit claims, pagination reset, original ordering,
and current/stale/legacy saved reports with unchanged archive bytes.
